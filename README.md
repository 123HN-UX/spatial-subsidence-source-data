# Spatial subsidence: selected source data

Supporting selected analyses in:
Spatially variable subsidence reveals local relative elevation loss obscured by regional averaging in the western Pearl River Estuary

Contact: Nan Huang, Shandong University of Science and Technology, China; huangnan@sdust.edu.cn.

## Contents

Twelve CSV source-data tables copied without modification from the manuscript preparation source-data folder. See DATA_DICTIONARY.md for descriptions, columns and row counts, and manifest.json / SHA256SUMS.txt for integrity checks. Historical figure numbers in filenames may differ from the final manuscript.

## Coverage

This selected tabular source-data bundle is not a complete reproducibility archive. It excludes the full geocoded InSAR raster time series, masks, analysis scripts, environment, and other intermediate products. A public release of this bundle alone must not be described as deposition of all study data.

## Upstream public inputs

- NGL COA1 IGS20: https://geodesy.unr.edu/gps_timeseries/IGS20/tenv3/IGS20/COA1.tenv3
- IPCC AR6 projections: https://doi.org/10.5281/zenodo.6382554
- Paired Hato FVCOM: https://doi.org/10.5281/zenodo.3572509 (De Dominicis et al., 2020; CC BY 4.0, as cited in the manuscript). The two S3 CSVs are derived selections / response metrics. Cite the original archive and retain its licence attribution.
- ESA WorldCover 2021 and Copernicus GLO-30: upstream study inputs, not redistributed in this bundle.

These references identify upstream inputs, not a public accession for the study-specific InSAR archive.
